# Technik 7 – Übungsportal

Übungen für Technik in Jahrgang 7:

- **Technisches Zeichnen:** Bemaßungsregeln, Linienarten, Lückentext, Kreuzworträtsel, Fehlersuche, Maße berechnen, Bohrungen bemaßen, Zeichnungsarten
- **Bohren & Sicherheit:** Bauteile der Tischbohrmaschine, Sicherheitsregeln, Werkstattordnung, Bohrer, Lochtypen, Arbeitsschritte
- **Abschlusstest** mit gemischten Fragen

Die Seite braucht keine Anmeldung und speichert nichts auf einem Server. Die Sterne für den Fortschritt liegen nur im Browser des jeweiligen Geräts.

## Dateien

| Datei | Inhalt |
|---|---|
| `index.html` | Grundgerüst der Seite |
| `daten.js` | **Alle Fragen und Texte** – hier kann man Fragen ändern oder ergänzen |
| `app.js` | Übungsarten und Seitenaufbau |
| `zeichnung.js` | Zeichnet die technischen Zeichnungen (Bemaßung) |
| `style.css` | Aussehen |
| `bilder/` | Bild der Tischbohrmaschine |
